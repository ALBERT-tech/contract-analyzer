# Проверка прямой закупки по 223-ФЗ

Публичный прототип на четырёх полностью вымышленных договорах. Правила и суммы в учебном положении иллюстрируют работу интерфейса. Действующую редакцию положения конкретного заказчика нужно загрузить отдельно.

[Открыть демо](https://albert-tech.github.io/contract-analyzer/ep-review-223/) · [Скачать приложение](https://albert-tech.github.io/contract-analyzer/ep-review-223/ep-review-223.zip)

В каждом сценарии показаны предмет и цена договора, пункт заказчика, условия подходящих оснований и дословные цитаты. Выбор сценария выполняется в браузере.

## Свои документы

Распакуйте архив и запустите **start.cmd** на Windows с Python 3.10 или новее. При первом запуске понадобится доступ к интернету для установки PyMuPDF. Сервис откроется на http://127.0.0.1:8769/. Для обработки новых документов требуется работающая текстовая модель с OpenAI-совместимым API. По умолчанию используется локальная Ollama на http://127.0.0.1:11434/v1.

Для другого адреса или конкретной модели задайте переменные окружения LLM_BASE_URL и LLM_MODEL перед запуском. При необходимости задайте LLM_API_KEY на своём компьютере. При загрузке документов текст передаётся выбранной модели. Извлечённые правила сохраняются в SQLite в каталоге data локальной установки.

Загрузите основной текст и поправки в порядке принятия, затем выберите договор со спецификацией в одном файле. Форматы — PDF с текстовым слоем, DOCX или TXT. Для сканов нужен OCR. Сервер сверяет цитаты с загруженным текстом и возвращает результаты по каждому извлечённому основанию. Полнота и качество извлечения для новой редакции зависят от модели.
