# Проверка прямой закупки по 223-ФЗ

[Открыть приложение](https://albert-tech.github.io/contract-analyzer/ep-review-223/) · [Скачать локальную версию с ИИ](https://albert-tech.github.io/contract-analyzer/ep-review-223/ep-review-223.zip)

Выберите Положение из ЕИС и договор конкретного заказчика. Вопросительные знаки рядом с полями открывают подсказки по наведению, фокусу с клавиатуры или нажатию. Форматы — DOCX, PDF с текстовым слоем и TXT, до 14 МБ на файл. Скан предварительно распознайте. Спецификацию включите в файл договора.

На GitHub Pages введите свой ключ AgentPlatform и нажмите **Проверить и применить**. Запрошенный ID — google/gemini-3.1-flash. Подключение сверяет его с каталогом вашего ключа. Если доступна версия Flash-Lite, выберите её точный ID в поле модели. При загрузке файлов браузер отправляет извлечённый текст напрямую в AgentPlatform по OpenAI-совместимому API (POST https://api.agentplatform.ru/v1/chat/completions, Authorization: Bearer). Ключ хранится только в памяти текущей вкладки. Используются квоты и тариф вашего проекта AgentPlatform. Модель формирует каталог по Положению, извлекает факты договора и проверяет каждое основание. Код проверяет цитаты, полноту списка оценок и числовые сравнения.

Для локальной версии распакуйте архив и запустите **start.cmd** на Windows с Python 3.10 или новее. Первый запуск устанавливает PyMuPDF. Сервис открывается по адресу http://127.0.0.1:8769/. По умолчанию он обращается к локальной Ollama на http://127.0.0.1:11434/v1. Для другого OpenAI-совместимого API задайте LLM_BASE_URL, LLM_MODEL и, при необходимости, LLM_API_KEY. При выборе файлов извлечённый текст отправляется настроенному провайдеру, а правила Положения сохраняются в SQLite на этом компьютере.
